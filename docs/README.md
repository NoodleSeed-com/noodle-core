# Noodle Core documentation

**Owns:** The public documentation map for contributors and self-host operators.
**Read when:** Choosing the smallest guide for a Noodle Core task.
**Do not put here:** Detailed procedures, duplicated configuration tables, or Noodle Seed Cloud operations.
**Update when:** A public guide is added, removed, or changes ownership.

## Run and operate Noodle Core

- [Self-hosting](self-hosting.md) — initialize, boot, deploy, call, restart, inspect, and reset the local stack.
- [Configuration](configuration.md) — canonical environment values, secrets, OAuth groups, and reconciliation.
- [Security](security.md) — trust boundaries, loopback defaults, internet exposure, and operator duties.
- [Backup and restore](backup-and-restore.md) — capture and restore PostgreSQL, assets, and the encryption key.
- [Compatibility and upgrades](compatibility-and-upgrades.md) — supported toolchain, protocols, `0.x` policy,
  and the upgrade/downgrade boundary.

## Understand and explore

- [Architecture](architecture.md) — public components, data flow, certified defaults, and commercial boundary.
- [Connector development](connector-contributions.md) — design and test HTTP/compute capability through the
  TypeScript authoring surface; see CONTRIBUTING for intake status.
- [Governance](governance.md) — repository authority, maintainership, licensing, and the future contribution flow.
